# Prysma Launchpad Contracts

Invite-gated token launches on Uniswap v4. Creators open a Continuous Clearing Auction; after graduation, proceeds seed a locked v4 pool. This repo adds invite validation and hook-based fee distribution on top of Uniswap’s Liquidity Launchpad.

**Full documentation: [docs.prysma.trade](https://docs.prysma.trade)**
